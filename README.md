# ♞ Chess Master - Mobile MVC

Game catur berbasis web yang interaktif dan dioptimalkan khusus untuk tampilan perangkat *mobile*. Proyek ini dibangun murni menggunakan HTML, CSS, dan Vanilla JavaScript dengan menerapkan pola arsitektur MVC (Model-View-Controller).

## 🌟 Fitur Utama

* **Mode PvP (Lokal):** Main *By One* bersama teman di satu layar yang sama.
  * **Santai:** Bermain bebas tanpa batasan waktu.
  * **Kompetitif:** Bermain dengan sistem waktu (Timer) untuk setiap pemain.
* **Mode vs Komputer (AI):** Tantang AI dengan 3 tingkat kesulitan:
  * 🟢 **Mudah:** Cocok untuk pemula.
  * 🔵 **Normal:** Standar permainan biasa.
  * 🔴 **Sulit:** Tantangan kelas Master.
* **Fitur Catur Lengkap:** Mendukung aturan catur standar termasuk *Check* (Skak), *Checkmate* (Skakmat), *Pawn Promotion* (Promosi Bidak), dan panel riwayat bidak yang dimakan.
* **Desain UI/UX Modern:** Dilengkapi dengan *Dark Mode* dan *Light Mode*, efek blur (Glassmorphism), serta animasi transisi yang mulus.
* **Mobile First:** Dirancang sedemikian rupa agar nyaman dimainkan melalui *smartphone* maupun tablet tanpa perlu aplikasi tambahan.
